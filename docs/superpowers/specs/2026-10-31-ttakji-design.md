# 딱지치기 추가

작성일: 2026-10-31
상태: 구현됨 (2026-10-31)

## 1. 목표

새 게임 3종(숫자야구 → 딱지치기 → 장기) 중 두 번째. 검색 유입이 많은 "한국 전통 놀이"(윷놀이·알까기) 묶음에 딱지치기를 더한다. 숫자야구 때 만든 새 게임 연결 방식(메뉴·홈·영어판·문구)을 그대로 따른다. 게임 페이지는 처음부터 규칙·요령·판정 방식·AI 설명·FAQ를 게임 아래에 함께 둔다.

## 2. 확정 요구사항

| 항목 | 결정 |
|---|---|
| 조작 | 조준 + 힘 게이지: 바닥 딱지 근처를 찍어 조준점, "치기"로 게이지 시작, 한 번 더 눌러 그 세기로 내리침 (키보드: 스페이스바) |
| 규칙 | 딱지 따먹기: 각자 5장. 바닥에 놓인 상대 딱지를 침. 뒤집으면 따고 한 번 더(상대의 다음 딱지가 놓임), 못 뒤집으면 공수 교대. 상대 딱지를 모두 따면 승리 |
| 판정 | 위치·세기로 뒤집힐 확률을 계산하고 난수 하나로 결정 (최대 92%) |
| 모드 | AI 대전(쉬움·보통·어려움), 한 화면 2인 대전, 온라인 대전(방 코드) |
| 온라인 운 | 서버가 난수만 정하고, 판정 계산은 양쪽 브라우저가 같은 식으로 (윷놀이 방식) |
| 선공 | AI 대전은 판마다 번갈아(첫 판 사람 선공). 온라인은 방장 선공, 재대결마다 번갈아 |
| 점선 가이드 | "잘 뒤집히는 가장자리" 점선은 쉬움 AI 대전에서만 표시 (들뜬 변 쪽은 노란색) |
| 주소 | `/ttakji`, `/en/ttakji` |

## 3. 비목표 (YAGNI)

- 딱지 종류(무게·크기)별 차이, 딱지 꾸미기
- 실제 물리 시뮬레이션(종이 휨·공기 흐름) — 확률 판정식으로 대신한다
- 온라인 턴 제한 시간
- 한 판 중간 재접속 시 내리치는 애니메이션 재생 (마지막 확정 상태로만 복구)

## 5. 화면과 흐름

- 위에서 내려다본 시점. 가상 판(예: 400×400)에서 계산하고 화면 크기에 맞춰 그린다(CSS 폭 100%, 최대 크기 제한 — 알까기 수정 때와 같은 방식).
- 맨 위: 양쪽 장 수(작은 딱지 모양). 가운데: 바닥에 놓인 상대 딱지 1장(놓일 때마다 각도가 조금씩 다름). 아래: 힘 게이지와 "치기" 버튼.
- 흐름: 조준점 찍기(다시 찍으면 이동) → "치기"(게이지 시작) → 다시 눌러 멈춤 → 내 딱지가 위에서 떨어지는 애니메이션 → 뒤집히면 상대 딱지가 들렸다가 뒷면으로 떨어짐 → 결과 표시.
- 게이지: 바늘이 0→100% 왕복. 90% 이상 구간에서는 바늘이 빨라져 정확히 멈추기 어렵다.
- 2인 대전은 같은 화면에서 번갈아 친다(숨길 정보 없음).
- 결과 창: 승리/패배(AI) 또는 빨강·파랑 승리(2인), 다시 하기 → 모드 선택 화면. 재시작 버튼도 모드 선택 화면으로(다른 게임과 같음).
- 모드 선택: AI 대전 → 난이도 / 1:1 하기 / 온라인 대전(방 생성·입장).

## 6. 판정식 (`TtakjiCore.flipChance`)

- 바닥 딱지: 한 변 S, 중심과 각도 θ. 조준점을 딱지 기준 좌표(u, v)로 바꿔 `m = max(|u|, |v|) / (S/2)` (가운데 0, 가장자리 1, 바깥 > 1).
- 위치 점수 e(m), 구간 선형: (0, 0.12) → (0.5, 0.3) → (0.85, 1.0) → (1.0, 1.0) → (1.15, 0.6) → (1.6, 0), 1.6 넘으면 0(헛손질).
- 세기 점수 f(p) = p^1.5 (p: 0~1).
- 들뜬 변 보정 s (2026-10-31 사용자 요청으로 추가): 딱지마다 한 변이 들떠 있다(k로 정하는 고정값, 표 `[0, 2, 1, 3, 2, 0, 3]`, 변 0 = +u, 1 = -u, 2 = +v, 3 = -v). 딱지를 대각선으로 네 조각 냈을 때 친 곳이 들뜬 변 쪽 조각(바깥 포함)이면 s = 1, 나머지 세 변 쪽이면 0.65. 들뜬 변 쪽으로만 그림자를 넓고 진하게, 테두리를 살짝 밝게 그려 화면으로 알아볼 수 있게 한다. 목적: 그림자를 읽는 사람과 아닌 사람 사이에 실력 차가 생기게.
- 뒤집힐 확률 P = min(0.92, 0.92 · e · s · f). 난수 r(0~1)이 r < P면 뒤집힘.
- 바닥 딱지 각도는 놓인 순서 k로 정하는 고정값(예: 표에서 k번째)이라 온라인 양쪽이 같다.
- 계수는 구현 중 AI 실측으로 조정할 수 있고, 조정하면 이 문서와 본문 표를 함께 고친다.
- 목표 감각: 잘 치는 사람이 10번에 7~8번 뒤집는 정도.

## 7. AI

판정식은 사람과 같고, 들뜬 변을 알아보는지와 조준·세기의 정확도로 난이도를 나눈다.

| 난이도 | 조준 | 세기 | 목표 성공률 |
|---|---|---|---|
| 쉬움 | 들뜬 변 무시, 딱지 위 아무 곳 | 42~92% 들쭉날쭉 | 약 25% |
| 보통 | 절반쯤만 들뜬 변, 가장자리 근처, 흔들림 큼 | 86% 안팎 | 약 50% |
| 어려움 | 늘 들뜬 변의 가장자리 바로 안쪽, 흔들림 작음 | 92% 안팎 | 약 75% |

- AI 차례에도 조준점과 게이지 움직임을 보여 주고 1초 남짓 뒤에 친다.
- 실측으로 성공률이 목표에서 벗어나면 흔들림 크기를 조정한다.
- 들뜬 변 규칙 반영 후 실측(2026-10-31, 난이도별 10,000번): 쉬움 25.1% / 보통 51.3% / 어려움 73.6%. AI끼리 1,000판 어려움 vs 보통 900승 100패. 사람이 들뜬 변을 매번 찾아 세기 90%에서 멈추면 79%.

## 8. 온라인 (서버는 난수만)

- **`hit`** `{ seq, x, y, power }`: 서버는 seq·차례·값의 범위(x, y는 가상 판 안, power 0~1, 숫자)를 확인하고 `crypto.getRandomValues`로 난수 r을 만들어 `{ type: 'hit', by, x, y, power, roll, seq, turn }`을 양쪽에 보낸다. 차례는 넘기지 않는다.
- 양쪽 브라우저가 같은 입력으로 `flipChance`와 r을 비교해 같은 결과·애니메이션을 낸다.
- **`move`**(기존 경로): 결과가 나오면 친 쪽이 `{ nextTurn, state: { counts, k } }`를 보낸다. 뒤집었으면 nextTurn = 나, 아니면 상대. 받는 쪽은 상태를 맞춘다(이미 같은 결과를 계산했으므로 대조만).
- 재접속: 마지막 `move` 상태로 복구. 재대결: 5:5, 선공 교대(room.js에 딱지치기를 선공 교대 게임으로 등록).
- 한계: 결과(난수)는 조작 불가. `move`의 다음 차례는 친 쪽이 보내므로 코드를 고친 클라이언트는 거짓 차례를 보낼 수 있다(윷놀이와 같은 수준). 차례는 양쪽 모두 서버가 알려 주는 값을 따른다(받는 쪽 계산과 달라도 화면이 서버와 어긋나지 않게).
