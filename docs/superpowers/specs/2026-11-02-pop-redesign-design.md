# 디자인 개편: 놀이판 팝

작성일: 2026-11-02
상태: 설계 승인됨, 문서 검토 대기

## 1. 목표

사용자 의견: 지금 디자인이 너무 단조롭다. 더 역동감 있고 개성 있게.

- 역동감: 누르고 이기는 순간의 손맛과 축하 연출
- 개성: 장난감·보드게임 상자 같은 "놀이판 팝" 성격, 분류별 색으로 페이지마다 다른 얼굴
- 지켜야 할 것: 글자 대비(WCAG AA 4.5:1), 동작 줄이기 설정 존중, 휴대폰 360px에서 넘침 없음, 첫 화면이 눈에 띄게 무거워지지 않을 것, 게임 아래 본문이 읽기 좋을 것(애드센스 재신청 대비)

## 2. 확정 사항

| 항목 | 결정 |
|---|---|
| 범위 | 홈 + 게임 페이지의 공통 틀(글꼴·색·메뉴·제목·상태 표시·모드 선택 창·버튼·결과 창·게임 방법·본문·바닥글). 14개 게임판 그림과 공략·개발 일지 글 페이지의 배치는 그대로 |
| 방향 | A. 놀이판 팝: 굵은 검은 테두리, 각진 색 그림자, 눌리는 버튼, 분류 색 |
| 움직임 | 2단계: 손맛 + 축하 연출(색종이·숫자 세기·카드 물결 등장). 배경 움직임·효과음 없음 |
| 구현 | 공용 style.css를 새 디자인으로 다시 쓰기 + 게임 페이지 공용 스크립트 하나(`fx.js`). 홈의 카드 등장은 CSS만 |

## 3. 색

| 이름 | 값 | 쓰임 | 대비 |
|---|---|---|---|
| 바탕 | `#191310` | body | 글자 16.1:1 |
| 카드 | `#2a201a` | 카드·판·창 | 글자 13.9:1 |
| 카드 2 | `#352820` | 보조 버튼, 표 줄무늬 | |
| 글자 | `#f6efe3` | 본문 | |
| 흐린 글자 | `#b8a893` | 설명·보조 | 카드 6.9:1, 바탕 7.9:1 |
| 먹 | `#000` | 테두리 2.5px, 각진 그림자 | |
| 빨강 (전통 놀이) | `#d63526` | 분류 색 | 흰 글자 4.8:1 |
| 파랑 (두뇌 대결) | `#2f6fe5` | 분류 색 | 흰 글자 4.6:1 |
| 노랑 (퍼즐·도구, 주 버튼) | `#ffcf3f` | 분류 색, 주 버튼 | 먹 글자 12.6:1 |

- 분류 색 위 글자: 빨강·파랑은 순백(`#fff`), 노랑은 먹(`#1a1208`). 투명도로 흐리게 하지 않는다(대비가 떨어진다).
- 분류 색은 글자 뒤에 깔지 않는다. 제목 밑줄은 글자 아래에 따로 긋는다(노랑 위 밝은 글자는 안 읽힌다).
- 기존 변수 이름 유지(인라인 스타일 약 230곳이 쓴다):
  - `--accent-blue`(대부분 링크 글자색, 약 207곳) → 노랑 `#ffcf3f`(바탕 대비 12.5:1)
  - `--accent`(배경으로 쓰는 곳) → 빨강 `#d63526`
  - `--accent-blue`를 배경으로 쓰는 약 25곳은 흰 글자와 짝이라 노랑이 되면 안 읽힌다 → 구현 때 하나씩 확인해 `--accent`나 버튼 클래스로 바꾼다
- 게임판 색 변수(`--board-wood`, `--stone-*`, `--grid-line`)는 바꾸지 않는다.

### 페이지별 분류 색

게임 페이지 `<body data-cat="…">`로 `--cat`, `--cat-ink`를 정한다.

| data-cat | 색 | 게임 |
|---|---|---|
| `trad` | 빨강 | 윷놀이, 알까기, 딱지치기 |
| `brain` | 파랑 | 오목, 체스, 리버시, 사목, 점잇기, 틱택토 |
| `solo` | 노랑 | 숫자야구, 스도쿠, 지뢰찾기, 2048, 사다리타기 |
| (없음) | 빨강 | 홈·공략·개발 일지·소개 등 나머지 |

분류 색이 쓰이는 곳: 메뉴의 현재 게임 알약, 제목 밑줄, 선택된 모드 버튼, 본문 소제목 밑줄과 목록 기호, 홈 묶음 스티커와 카드 그림자.

## 4. 글꼴

- 제목: **Black Han Sans** (Google Fonts, 한 가지 두께). h1·h2·모드 제목·결과 제목·주 버튼·홈 카드 이름
- 본문: **Pretendard Variable** (jsDelivr `orioncactus/pretendard@v1.3.9` dynamic-subset). 화면에 나온 글자 조각만 내려받는다
- Outfit(영문 전용)은 36개 페이지에서 뺀다. `preconnect`는 fonts.googleapis.com·fonts.gstatic.com·cdn.jsdelivr.net
- `font-display: swap`(두 곳 모두 기본값). 글꼴이 늦게 와도 시스템 글꼴로 먼저 보인다
- 숫자가 흔들리지 않게 점수·타이머에는 `font-variant-numeric: tabular-nums`

| 부품 | 모습 |

| 상태 `.game-info` | 카드 판. `.status-message`는 강조 글씨, 차례가 바뀌면 한 번 튐(§6) |

| 결과 창 `.overlay .modal` | 테두리 3px, 그림자 8px. 제목은 노랑 큰 글씨+먹 외곽선(`-webkit-text-stroke`)+각진 글자 그림자, -3° 기울임. 패배·무승부 제목은 밝은 글자(색종이 없음) |

## 6. 움직임과 축하

### 규칙
- `transform`, `opacity`만 움직인다(레이아웃을 바꾸는 속성 금지)
- 누름 0.08초, 마우스 올림 0.15초, 나타남 0.35~0.45초 `cubic-bezier(.3,1.5,.5,1)`(살짝 튕김), 사라짐 0.15초
- `prefers-reduced-motion: reduce`: 기존 style.css 규칙(모든 애니메이션 0.01ms)을 유지하고, `fx.js`는 색종이를 만들지 않으며 숫자는 바로 최종값

### 손맛 (CSS)
- `.btn`, `.mode-btn`, `.game-card`, `.game-nav-item`: 올림 `translate(-1px,-2px)`+그림자 커짐, 누름 `translate(4px,4px)`+그림자 0
- 모드 선택 창 `.game-mode-card`의 직속 단계 `div`에 등장 애니메이션. 단계는 `hidden`(display:none)으로 숨겼다 보이므로, 보일 때마다 CSS 애니메이션이 다시 실행된다(스크립트 불필요)

### 공용 스크립트 `fx.js` (14개 게임 페이지, defer)
게임 코드는 고치지 않는다. 화면 변화를 감지해 연출만 붙인다.

1. **차례 튐**: `.status-message`의 글자가 바뀌면(MutationObserver) `fx-pop` 클래스를 붙였다 떼어 0.3초 튐
2. **결과 창**: `.overlay`(단 `#room-panel` 제외)가 `hidden`이 빠지며 보이면
   - 승리 판정: 창 안 `h2` 글자가 `/승리|Wins?!|정답|완성|Solved|달성|reached 2048/`에 맞고 `/패배|Lose|무승부|Draw|펑|Boom|게임 오버|Game Over/`에 안 맞으면 승리
   - 승리면 화면 전체 고정 캔버스에 색종이(빨강·파랑·노랑, 약 90조각, 1.5초) 후 캔버스 제거
   - 창 안 `p`의 숫자(2 이상 정수, 앞뒤에 `:`가 없는 것)를 0부터 0.6초 동안 세어 올림. 다른 스크립트가 같은 글자를 다시 바꾸면 세기를 멈추고 그 값을 따른다
3. 실패해도 게임에 영향 없게 모든 처리를 try/catch, 대상 요소가 없으면 아무것도 하지 않음

### 홈
- 카드가 묶음별로 물결처럼 등장(카드마다 0.04초 지연, CSS `animation-delay`)

## 7. 홈 화면 (`index.html`)

- 첫머리: "오목**보드**"(보드는 노랑) 큰 Black Han Sans + 먹 그림자. 둘레에 바둑돌·딱지 스티커 장식(정지, `aria-hidden`). 스티커 "설치 없이, 가입 없이, 바로 한 판!", 알약 "게임 14종 · AI 대전 · 온라인 대전 10종 · 한국어/English"
- 묶음 제목: 분류 색 스티커(-1.5°)에 게임 수 배지
- 카드: 카드 판 + 분류 색 각진 그림자, 이름 Black Han Sans, 설명 흐린 글자, "플레이 →" 노랑 알약. 미니 판 그림은 지금 것을 그대로(테두리만 추가)
- 읽을거리: 왼쪽 굵은 색 띠 카드
- 휴대폰: 카드 2열 유지, 첫머리 글씨 크기 축소, 장식 스티커 위치 조정(넘침 없게)

## 8. 비목표

- 14개 게임판 그림 다시 그리기, 공략·개발 일지 글 페이지 배치 변경(색·글꼴은 공용 style.css를 따라 자동으로 바뀐다)
- 밝은 테마, 효과음, 배경 움직임, 페이지 전환 연출
- 애니메이션 라이브러리 도입

## 9. 영향과 확인

- 바뀌는 파일: `style.css`(다시 쓰기), `index.html`(홈 스타일·마크업), 36개 HTML의 글꼴 링크, 14개 게임 HTML의 `data-cat`·`fx.js`, 새 `fx.js`, 인라인 스타일 중 `--accent-blue` 배경 사용처, `build-en.js`로 영어판 재생성
- 본문 글자는 바뀌지 않으므로 수정일(page-dates)은 바뀌면 안 된다. 바뀌면 되돌린다
- 확인:
  - 14개 게임 모두 모드 선택 → 한 판 끝까지 → 결과 창(승리 시 색종이, 패배 시 없음) → 다시 하기
  - 온라인 방 창 열림·닫힘
  - 360·375·768·1280px 넘침 없음, 영어판
  - 대비 검사(디자인 검사 도구 + 직접 계산), 키보드 포커스 보임
  - 동작 줄이기 켠 상태에서 움직임 없음
  - 첫 화면 무게: 바뀌기 전후 홈·오목 페이지의 내려받는 글꼴 용량 비교
  - 스모크 테스트, 서버 테스트(변화 없어야 함)
- 배포 전 사용자 확인
