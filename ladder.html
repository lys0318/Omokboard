  • 팁: 사다리는 위아래 순서만 바뀌지 않을 뿐, 어떤 번호가 어디로 갈지는 완전히 무작위입니다The vertical order never crosses over, but which number lands where is completely random

사다리타기, 이렇게 즐기세요

사다리타기(아미다쿠지)가 항상 공평한 이유는 수학적으로 명확합니다. 세로줄은 서로 교차하지 않고 가로줄은 한 단에서 겹치지 않으므로, 사다리를 아무리 복잡하게 그려도 번호 하나당 결과 하나가 정확히 1:1로 대응합니다.

가로줄 위치는 매번 완전히 무작위로 생성되어 미리 결과를 예측하거나 조작할 수 없습니다. 술자리 벌칙, 청소 당번, 발표 순서 정하기처럼 다툼 없이 공정하게 결정할 일이 있을 때 활용해보세요.

How to Enjoy the Ladder Game

A ladder game (Amidakuji) is mathematically guaranteed to be fair. Vertical lines never cross, and rungs never overlap within a row, so no matter how complex it looks, every number maps to exactly one result — a true one-to-one match.

Rung placement is fully random each time, so the outcome can't be predicted or rigged in advance. Use it to fairly decide who pays, who's on cleanup duty, or the order of presentations — no arguing needed.
