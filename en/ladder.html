빈칸에 입력 후 눌러 결과를 확인하세요Fill in a box, then tap it to reveal the result

게임 방법

  • 목표: 위쪽 칸과 아래쪽 결과를 무작위 사다리 경로로 이어, 공평하게 역할이나 순서를 정합니다Connect each top box to a bottom result through a random ladder path — a fair way to assign roles or order
  • 조작: 위쪽 칸은 비어 있습니다. 이름이나 숫자를 입력해야 그 칸을 눌러 경로를 볼 수 있습니다Top boxes start empty. Type a name or number first — only then does tapping the box trace its path
  • 전체 공개:Reveal All: 모든 경로를 한 번에 색으로 구분해 보여주고 목록으로 정리합니다Shows every path at once in different colors and lists the full mapping
  • 팁: 사다리는 위아래 순서만 바뀌지 않을 뿐, 어떤 번호가 어디로 갈지는 완전히 무작위입니다The vertical order never crosses over, but which number lands where is completely random
